- **Typography, radius & hit-target compliance (`PerformanceChart.tsx`, `Analytics.tsx`, `AIAnalysis.tsx`, `Performance.tsx`, `History.tsx`, `Switch.tsx`, `AccessibleChartFrame.tsx`, `Tabs.tsx`, `DataTable.tsx`, `Select.tsx`, `Toast.tsx`, `Sidebar.tsx`, `StatusChip.tsx`):** Raised remaining `11px` ECharts font entries to `12px`, replaced off-scale `rounded-sm` in `History.tsx` with `rounded-[var(--radius-control)]`, added inline `Switch` variant (`min-h-[40px]`), and standardized `>= 40px` (`h-10`) interactive hit targets across shell, list, and task pages.
- **Global status strip & undoable destructive/bulk workflows (`App.tsx`, `Inventory.tsx`, `Automation.tsx`):** Added clickable global health strip across sub-pages routing to `/alerts` or `/analytics`; added row checkboxes + Bulk Action Bar (`Probe selected`, `Remove custom` with `Dialog` confirmation and `Undo` restore) in `Inventory.tsx`; and added `Undo` restore toasts when deleting schedules in `Automation.tsx`.

## Phase 1 — Design System Foundation, App Shell & Shared Primitives
- **Audit completed across 38 source files:** Identified 34 hard-coded hex colors, 104 sub-12px typography occurrences (`9px`, `10px`, `11px`), off-grid spacing tokens, 11 disparate border radius values, duplicated KPI/table/modal markup, and 10 redundant page-title banner cards.
- **Dual-theme token system (`globals.css`):** Implemented a 4-step near-neutral dark surface ladder (`#090c12` → `#10151f` → `#171e2c` → `#1f283a`) and matching light theme (`#f6f8fb` → `#ffffff` → `#edf1f7` → `#e2e8f2`) with WCAG AA/AAA verified text (`>= 5.17:1`) and UI control boundary (`>= 3.25:1`) contrast. Removed decorative radial glows and neon box shadows.
- **Typography & scale enforcement:** Standardized on Inter (UI) and JetBrains Mono (`tabular-nums` data only) across the strict `12 / 13 / 14 / 16 / 20 / 28` px scale with zero text below `12px`, sentence-case headings and navigation groups, and 4-point spacing (`4/8/12/16/24/32/48/64`) with three radii (`8px`, `12px`, `999px`).
- **Shared component library (`components/ui/*` + `KpiCard`):** Built and standardized `Button` (primary, secondary, ghost, destructive), `TextInput`, `Select`, `Switch`, `Tabs`, `StatusChip` (color + icon + text), `Card`, `DataTable` (sticky header, sortable columns, right-aligned numeric columns, comfortable/compact density), `Tooltip`, `Toast`, `Dialog` (focus-trapped confirmation), `SideDrawer`, `Skeleton`, `EmptyState`, `ErrorState`, `KpiCard` (value, unit, delta, SVG sparkline, threshold color), `CopyButton`, and `ThemeToggle`.
- **App shell rebuild (`Sidebar`, `TopBar`, `CommandPalette`, `App.tsx`):** Made sidebar scrollable with active-section highlighting, persisted collapse state (`localStorage` + `[`), and sentence-case groups; upgraded `TopBar` with global status, `15m–7d` time-range selector, live freshness/stale warning indicator, `Sync`, and theme switcher; unified `<main>` max-width (`1200px`) and padding across all views.
- **Removed redundant title banners:** Removed 10 repeated banner cards across `Diagnostics`, `Performance`, `Automation`, `AIAnalysis`, `Alerts`, `Analytics`, `History`, `Reports`, `SystemInfo`, and `Topology` that duplicated the page `<h1>` title.
- **Component gallery (`/design-system`):** Added a dedicated gallery page displaying every shared component and interactive state across both Dark and Light themes.
- **Visual QA defects resolved (after live desktop/tablet/mobile inspection):**
  - Portaled `Dialog`, `SideDrawer`, and `CommandPalette` to `document.body` so overlays always cover sticky `TopBar` and `Sidebar` headers.
  - Switched `Sidebar` breakpoint to `lg` (`>=1024px`) and used overlay drawer below `1024px`, eliminating the `111.2px` tablet (`768px`) horizontal overflow and clipped TopBar controls.
  - Replaced native `<select>` elements in `TopBar` and `Select.tsx` with an accessible custom listbox (`40px`), fixing double-arrow rendering and top-aligned text.
  - Added explicit `sentiment` (`good` / `bad` / `neutral`) to `KpiCard` deltas so `-0.2ms` latency shows green and `+1.5%` loss shows red.
  - Fixed `Button` loading opacity in Light theme (`opacity-90` instead of `opacity-50`), TopBar warning label (`Slow · <ms>` instead of `Healthy`), `Slider` left-aligned min tick (`2s` vs `Default` overlap), `Tabs` mobile `flex-wrap`, and `Diagnostics` primary CTA token (`--accent`).

## Phase 2 — Data Integrity & Trust Fixes
- **Single canonical pass-rate metric & window (`core/engines.py`, `backend/main.py`, `Overview.tsx`, `Analytics.tsx`):** Updated `/api/analytics` to accept `window` (`15m`, `1h`, `6h`, `24h`, `7d`, `all`) and `limit`, returning one shared `pass_rate_pct` + `window_label` sourced directly from SQLite `test_history`. Overview and Analytics now bind to the same global `timeRange` selector so pass rates always match.
- **No zero-latency coercion on failed probes (`core/engines.py`, `PerformanceChart.tsx`, `Analytics.tsx`):** Failed/missing probe runs emit `None`/`null` for RTT latency and jitter instead of `0.0 ms`. ECharts renders gaps (`connectNulls: false`), shaded red outage `markArea` bands, vertical dashed `markLine` markers, and labeled `Outage` pins.
- **Real data-driven global health & alerting (`core/engines.py`, `backend/main.py`, `App.tsx`, `TopBar.tsx`, `Sidebar.tsx`):** Added `compute_global_health()` deriving `healthy`, `degraded`, or `critical` from the last 10 recorded probes and gateway latency (`> 150 ms`), logging deduplicated `Health Monitor` alerts into SQLite `events` and surfacing live degraded/critical status banners and pills across the app shell.
- **Consistent anomaly classifications & false-positive feedback (`core/diagnostics.py`, `core/engines.py`, `backend/main.py`, `AIAnalysis.tsx`):** Aligned `is_anomaly` classification with `packet_loss_pct > 0`, `jitter > 10.0 ms`, `avg_rtt > mean + 1.5σ`, and `IsolationForest` decision score so labels (`Anomaly`, `False positive`, `Normal`) strictly match reasons. Added `confidence_pct`, explicit `threshold`, `anomaly_feedback` SQLite persistence, and `POST /api/ai/false-positive/{test_id}` toggle controls.
- **Truthful database persistence indicator (`core/diagnostics.py`, `backend/main.py`, `StatusPanel.tsx`):** Replaced hardcoded `"In-Memory"` in `StatusPanel` with `SQLite (data/netpulse.db)` backed by `get_database_info()` on `/health`.
- **Distinguish `No data` from true zero (`utils/formatters.ts`, `Overview.tsx`, `Analytics.tsx`, `History.tsx`, `Diagnostics.tsx`):** Removed fake `100.0%` and `0.0ms` fallbacks when values are `null` or empty; empty metrics consistently display `No data`.
- **Standardized timestamps, units, and decimal precision (`utils/formatters.ts`, `History.tsx`, `Alerts.tsx`, `AIAnalysis.tsx`, `Analytics.tsx`):** Standardized all timestamps to `YYYY-MM-DD HH:mm:ss UTC` with relative-time hover tooltips, `1` decimal place for RTT (`ms`) and percentages (`%`), and `2` decimal places for jitter (`ms`) and throughput (`Mbps`).

## Phase 3 — Overview, Analytics & Network Topology Redesign
- **Overview (`Overview.tsx`, `KpiCard.tsx`, `ResourceGauge.tsx`):** Added plain-language top operational status banner (`X of Y targets failing since HH:MM:SS UTC · N active alerts`) with detail drill-down buttons; upgraded all 4 KPI cards with deltas, SVG sparklines, and drill-down routing; replaced tall radial RAM gauge with a compact horizontal threshold meter (`ResourceGauge`); added a problems-first **Active issues** rail + **Monitored target health** `DataTable`; embedded a compact interactive `TopologyGraph` preview with drill-down to `/topology`.
- **Analytics (`Analytics.tsx`, `core/engines.py`):** Upgraded percentile KPIs (`P50`, `P95`, `P99`, `Probe pass rate`) with plain-language tooltips, half-window deltas, and trend sparklines; added Dark/Light theme-aware ECharts with crosshair axis pointers, `dataZoom` slider + inside zoom/brush, and an **Aggregate trend / Compare targets** toggle; replaced the raw breakdown table with a sortable `DataTable` featuring inline per-target RTT sparklines and semantic threshold colors.
- **Network Topology (`TopologyGraph.tsx`, `Topology.tsx`, `globals.css`):** Eliminated ReactFlow's stray white attribution box and unstyled light buttons; replaced default nodes with theme-aware `TopologyNodeCard` nodes featuring device icons (`gateway`/`switch`/`server`/`probe`), live operational status, and measured RTTs; colored links by live target telemetry (solid green healthy, amber degraded, dashed red animated failing); added zoom/fit controls, `<MiniMap />`, live node search/center, resize `fitView`, node detail panel with `CopyButton` and drill-down actions, and an accurate link/role legend.

## Phase 4 — Unified List Views, Alert Lifecycle & 500+ Row Scale
- **Shared List Pattern (`ListViewToolbar.tsx`, `PaginationBar.tsx`, `useSavedViews.ts`, `export.ts`):** Built one consistent list architecture across Alerts, Test History, Anomaly Detection, and Inventory featuring debounced search, severity/status filter chips with live counts, time-window filtering, consecutive/repeated event grouping with expandable child occurrences, saved filter presets (`localStorage`), filtered CSV/JSON export, sticky headers, pagination (`25`/`50`/`100`/`250`), row hover, and focus-trapped detail `SideDrawer` inspection.
- **Alerts (`Alerts.tsx`, `core/diagnostics.py`, `core/engines.py`, `backend/main.py`):** Added persistent `open` / `acknowledged` / `resolved` lifecycle states and `snoozed_until` (`15m`/`1h`/`24h`) via additive SQLite columns and `POST /api/alerts/{id}/state` + `POST /api/alerts/bulk-state` routes; added bulk selection checkboxes, `New` arrival indicator, repeated-event de-duplication, and `Dialog`-confirmed clear.
- **Test History (`History.tsx`):** Added an interactive chronological **Pass / Fail Timeline Strip** above the table, consecutive/repeated failure grouping per target & protocol (`Failed ×N`), pagination up to 1,000 stored runs, and full run + target history `SideDrawer`.
- **Anomaly Detection (`AIAnalysis.tsx`):** Added an executive severity/change summary lead, an ECharts **Anomalies in RTT baseline context** chart with threshold marker, default anomalies-first table filtering with a `Show normal (N)` toggle, grouped anomaly inspection drawer, and collapsible **About this model** explanation panel.
- **Inventory (`Inventory.tsx`, `InventoryTable.tsx`, `core/engines.py`):** Merged monitored endpoints and host OS network adapters into one searchable, paginated table with inline SQLite latency (`avg_rtt_ms`) and `Last seen` UTC timestamps (replacing `"Click Ping to verify"`), muted quiet styling for `Down` adapters, detail `SideDrawer` with live probing, `Dialog`-confirmed deletion, and validated **Add node** modal.
